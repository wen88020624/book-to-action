# Product — Book to Action

> 最後對齊：2026-09-16  
> 本檔是**產品 North Star**。現行可實作範圍以 [SPEC.md](../SPEC.md) 為準；兩者衝突時，以本檔的方向為長期目標，以 SPEC 為短期交付邊界。

---

## 一句話

把書裡的方法論變成**可立刻在生活中實踐、可追蹤、可判斷適不適合自己**的互動體驗——解決「讀很多書，生活卻毫無實際改善」的困境。

---

## 我們要解決的問題

很多人讀完書只有「懂了」的感覺，卻缺少：

1. **從概念到行動的橋** — 方法論停在筆記裡，沒有可執行的下一步
2. **低摩擦的導入** — 不知道怎麼把書裡的步驟嵌進自己的日常
3. **誠實的回饋迴路** — 無法在短時間內知道「這套方法適不適合我」

因此價值單位不是「書」或「閱讀進度」，而是：**一次可驗證的生活實驗（Experiment）**，以及未來可復用的**方法論模板（Methodology Template）**。

---

## North Star 核心循環

```
書 / 平台模板
    ↓
方法論（可互動、可執行的說明與引導）
    ↓
立刻在生活中實踐（Experiment）
    ↓
紀錄發生了什麼（Log）
    ↓
快速知道「適不適合我」（Result + Rating）
```

成功指標（概念層，非 KPI 儀表板）：

- 從「理解概念」到「開始實踐」的時間要短
- 使用者能誠實回答：這套方法對我有幫助 / 部分有 / 沒有 / 還不知道
- 避免「收藏很多書、零行動」的結果

---

## 內容進入方式（雙軌）

光「導入書」就有很多路徑；也不一定要使用者自己貼全文。

| 軌道 | 說明 | 狀態 |
|---|---|---|
| **A. 使用者導入** | 使用者新增書 → 擷取／整理書中方法論 → 變成可互動的實踐流程 | MVP 已有「書 → Concept → Experiment」雛形；「方法論互動 Web / 全文導入」為後續 |
| **B. 平台上架模板** | 平台方整理好方法論模板，使用者直接套用開始實驗，不必自己導入文字 | 規劃中（Phase 之後） |

兩軌最終都匯入同一套：**Experiment → Log → Result**。  
書只是來源之一；模板、跨書合成的方法論也可以是來源。

### 軌道 A 的可能形態（尚未全部實作）

- 只填書名（現行 MVP）
- 貼上書中某段方法論說明 → 結構化成步驟／檢查清單／引導問題
- 匯出／匯入方法論草稿（未來）
- AI 輔助擷取（**明確非 MVP**；方向上可討論，實作需另開 Phase）

### 軌道 B 的可能形態（尚未實作）

- 平台策展的「方法論模板庫」
- 一鍵開始 Experiment（預填 title / description / 建議時長）
- 模板可標註來源書，但不強迫使用者先建 Book

## 與現行 MVP 的關係

| 層級 | 現行 MVP（見 SPEC） | North Star |
|---|---|---|
| 輸入 | Book（title only）+ 使用者自寫 Concept | 書摘／方法論文字、或平台模板 |
| 中間產物 | Concept（「我吸收了什麼」） | Methodology：可互動的說明 + 實踐引導 |
| 行動 | 手動建立 Experiment | 從方法論／模板一鍵或引導式開始 Experiment |
| 追蹤 | Freeform Log | 同樣以低摩擦紀錄為主；可選結構化步驟 |
| 結果 | Result + helpfulness rating | 同左——快速判斷適不適合自己 |

**設計原則不變：**

1. Experiments first — 首頁先看進行中的實驗，不是書架
2. Zero-friction logging — 紀錄越簡單越好
3. 「我吸收了什麼」優於「書上怎麼寫」
4. 誠實結果 —「還不知道」是合法且可永久保留的答案
5. No judgment — 不問「你成功了嗎？」、不秀失敗排行

---

## 產品邊界（持續有效）

### 我們是

- 閱讀 → 行動的轉換器
- 生活實驗追蹤器
- （未來）方法論模板平台

### 我們不是

- 讀書管理／書庫 App（ISBN、封面、進度條不是核心）
- 打卡／連續天數激勵工具
- 社交動態或書評社群（至少非近期）

---

## 給 AI 的決策啟發式

實作或提議功能前，問：

1. 這是否縮短「理解 → 開始實踐」？
2. 這是否讓人更容易追蹤並判斷「適不適合我」？
3. 這是否讓 Book／模板服務 Experiment，而不是反過來？
4. 若只對「收藏書」有幫助、對實驗無幫助 → **不做或降優先**
